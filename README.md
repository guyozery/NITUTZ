# NITUTZ

פרויקט הקורס "ניתוח ועיצוב מערכות מידע".

## התחלה

```bash
git clone https://github.com/guyozery/NITUTZ.git
```

פותחים את התיקייה ב-Claude Code. כל אחד מחבר אצלו את `sad-mcp` לפי ההוראות באתר הקורס.

## עבודה על משימה

```bash
git switch main
git pull
git switch -c feature/task-name
```

בסיום מעלים את הענף ופותחים Pull Request:

```bash
git push -u origin feature/task-name
gh pr create
```

הכללים המלאים נמצאים ב-[CLAUDE.md](CLAUDE.md).
